# stereometry-solver-bot

Учебный проект: Telegram-бот для решения задач по стереометрии.
Внутри две ML-модели: **фильтр** («задача / не задача») и **решатель** (LLM).

## Окружение

```bash
uv sync
```

## Сбор данных

Пайплайн из пяти шагов, каждый — отдельный скрипт в `parser/`. Данные
складываются в `data/raw/` (сырьё) и `data/processed/` (готовый датасет) —
обе папки не публикуются в репозитории (`.gitignore`), потому что часть
источников защищена copyright. В репозитории только код, который их
воспроизводит.

**1. ФИПИ, ЕГЭ и ОГЭ** — `parser/fipi_parser.py`

```bash
uv run python parser/fipi_parser.py
```

- ЕГЭ, «Математика. Профильный уровень» (`ege.fipi.ru/bank/`): темы КЭС
  7.2–7.4 → `fipi_ege_stereometry.jsonl` (позитив), тема 7.1 →
  `fipi_ege_planimetry.jsonl` (hard negative).
- ОГЭ, «Математика» (`oge.fipi.ru/bank/`): стереометрии в программе 9 класса
  нет вообще, поэтому берём только hard negatives — геометрию (=планиметрия,
  темы 7.1–7.6) → `fipi_oge_planimetry.jsonl` и алгебру (темы 2.x, 3.x) →
  `fipi_oge_algebra.jsonl`.

Технические детали (пагинация, кодировка, сломанный TLS-сертификат сайта,
обоснование легальности) — в докстринге файла.

**2. Прасолов, «Задачи по стереометрии» — основной источник позитива** —
`parser/prasolov_parser.py`

```bash
uv run python parser/prasolov_parser.py путь/к/Стереометрия-Прасолов.pdf
```

Задачника с ФИПИ (123 задачи) не хватает на позитивный класс нужного
размера. PDF книги (найден пользователем, не в репозитории — не публикуем
чужой PDF и не публикуем сырой извлечённый текст, авторское право) содержит
настоящий текстовый слой. Парсер: вырезает страницы раздела «Решения»,
режет оставшееся на отдельные задачи по номерам («2.9.», «3.12.»...),
отбрасывает задачи со ссылкой на рисунок и куски решений, случайно
просочившиеся мимо разбивки по страницам (детектируются по отсутствию
характерных слов условия — «докажите», «найдите» и т.п.) → 586 задач в
`prasolov_stereometry.jsonl`.

**3. SolidGeo (англ. → рус.) — рассмотрен и отклонён**

`parser/solidgeo_translator.py` в сборке **не используется** — код и
объяснение оставлены в репозитории как задокументированный тупик, чтобы
не наступать на те же грабли снова.

[SolidGeo](https://huggingface.co/datasets/SolidGeo/SolidGeo) — англоязычный
датасет из 3113 задач по стереометрии (CC-BY-NC-4.0). Оказался датасетом для
мультимодальных моделей — подавляющее большинство вопросов без картинки не
имеют смысла (числа на рисунке, не в тексте). Первая версия фильтра это
пропускала: после перевода ~60% текстов превращались в обрубки вида
«Найдите длину диагонали» без единого числа. Фильтр ужесточили (требовать
цифру в тексте + отсутствие слов-маркеров рисунка) — самодостаточными из
~3000 оказались только ~130. Даже эти немногие после машинного перевода
звучали недостаточно естественно — решение: не подмешивать SolidGeo вообще,
ни в каком объёме. Недостачу объёма (~91 из 800) закрывает
`parser/stereometry_template_generator.py` — свои параметризованные шаблоны
вместо чужого перевода.

**4. Мусор (easy negatives)** — `parser/junk_generator.py`

```bash
uv run python parser/junk_generator.py
```

Реальных датасетов «случайные сообщения боту» не существует — генерируется
по шаблонам (приветствия, болтовня, вопросы не по теме, мета-вопросы о
самом боте) → `junk_easy_negatives.jsonl`.

**5. Сборка финального датасета** — `parser/assemble_dataset.py`

```bash
uv run python parser/assemble_dataset.py
```

Объединяет все источники в пропорции **40% позитив / 40% сложный негатив
(планиметрия + алгебра) / 20% лёгкий негатив**, убирает дубликаты →
`data/processed/filter_dataset.jsonl` (1997 строк, формат `text`, `label`,
`category`, `source`). Позитив: 122 ФИПИ + 585 Прасолов + 93 свои шаблоны
(`parser/stereometry_template_generator.py`) — SolidGeo не используется.

### Известные ограничения

- В выборке из Прасолова остаётся единичный процент шума: PDF — сложная
  вёрстка LaTeX, детектор страниц «Решения» и фильтр по словам-маркерам
  условия ловят почти всё, но не гарантированно 100%.
- ~12% позитива (93 из 800) — сгенерированные шаблоны с параметрами, а не
  реальные задачи. Числа в них не всегда дают красивый ответ — для
  классификатора темы это не важно, для решателя использовать нельзя
  без доработки (сверки чисел и ответов).
