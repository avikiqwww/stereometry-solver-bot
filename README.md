# stereometry-solver-bot

Учебный проект: Telegram-бот для решения задач по стереометрии.
Внутри две ML-модели: **фильтр** («задача / не задача») и **решатель** (LLM).

## Окружение

```bash
uv sync
```

## Сбор данных

`parser/fipi_parser.py` — парсер открытого банка заданий ФИПИ
(`ege.fipi.ru/bank/`, раздел «Математика. Профильный уровень»).

```bash
uv run python parser/fipi_parser.py
```

Собирает все задания раздела и раскладывает по `data/raw/` на два файла:
- `fipi_stereometry.jsonl` — темы КЭС 7.2–7.4 (позитивный класс для фильтра);
- `fipi_planimetry.jsonl` — тема КЭС 7.1 (hard negative: похожий стиль, другая тема).

Технические детали и обоснование легальности источника — в докстринге самого файла.
Сырые данные не публикуются в репозитории (`.gitignore`) из-за copyright источника —
только код, который их воспроизводит.
